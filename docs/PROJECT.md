# Beaver AI Project

## Vision

Beaver AI is a voice-first, personalized learning platform for students. It is intended to grow into a broad educational platform, not a single-subject tutor or a voice-only chatbot.

The tutor should understand each student's goals, skill level, learning history, progress, weaknesses, and current work. Learning experiences should combine structured curricula, mastery tracking, adaptive instruction, personalized recommendations, and AI tutoring.

Coding is a major planned learning domain with specialized tools, but it does not define the product's full scope.

## Product Principles

1. **Understanding before answers.** Use explanations, questions, hints, practice, and feedback to help students learn rather than merely complete work.
2. **Personalization with continuity.** Adapt instruction using relevant goals, progress, mastery, and learning history.
3. **Voice-first, not voice-only.** Voice is a major interaction method within a broader learning experience.
4. **Structured and adaptive learning.** Connect tutoring to curricula, measurable mastery, and appropriate next steps.
5. **Motivation supports learning.** Gamification should encourage consistent, meaningful effort without displacing educational outcomes.
6. **Student trust and privacy.** Future parent or guardian insights must use appropriate permissions and preserve suitable student privacy.
7. **Broad, extensible scope.** Product and technical choices should support multiple learning domains over time.
8. **Incremental, startup-grade delivery.** Build in small, well-defined phases without sacrificing maintainability, quality, or safety.

## Current Scope

The repository is in its documentation and discovery stage. No application scope, target audience segment, technical stack, or launch milestone has yet been finalized.
